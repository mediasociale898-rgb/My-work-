State-Space Modeling & System Controllability

Essential Principles of Continuous Dynamics, Kalman Rank, & Closed-Loop Control

1. The State-Space Representation

Classical transfer function methods analyze systems from an input-output perspective in the frequency domain. In contrast, State-Space Modeling represents dynamic systems through first-order differential equations in the time domain, capturing both internal dynamics and external behavior.

Definition: State Vector x(t) The minimal mathematical vector of variables that completely describes the internal storage and physical state of a dynamic system at any given moment in time.

Standard Linear Continuous-Time Equations

  • State Differential Equation: x'(t) = A·x(t) + B·u(t)
  • Output Equation: y(t) = C·x(t) + D·u(t)

Where A is the system dynamic matrix (n×n), B is the input coupling matrix (n×m), C is the output observation matrix (p×n), and D is the direct transmission matrix.

3. The Controllability Criterion

A continuous system is said to be completely controllable if an unconstrained control input u(t) can steer any initial state x(0) to any target final state in finite time.

The Kalman Controllability Matrix C = [ B | A·B | A²·B | ... | Aⁿ⁻¹·B ]
The system is completely controllable if and only if the rank of matrix C equals the dimension of the state vector n (i.e. full row rank).
